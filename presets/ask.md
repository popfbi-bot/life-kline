# `life-kline add` 的四个问题

内部术语叫「开盘 / 最高 / 最低 / 收盘」，但对用户**不要用这些词**。
用户听不懂股市黑话，听得懂自己的日子。

## 依次问这四个

1. 早上起来的时候，你的状态大概几分？（0–10）
2. 今天最好的那个时刻，能打到几分？
3. 今天最糟的那个时刻，掉到几分？
4. 现在，睡前，几分？

## 然后两个可选项

- 成交量？记不住就回车跳过：
- 备注（可空）：

## 文案规则

- 不问「为什么」，不追问，不评价分数高低。
- 四个分数都跳过 = 那天记成停牌，合法。
- 只填一部分 = 报错，不猜。
- 句子结尾用「？」不用「?」，问号前不要加空格。

## 映射关系（仅内部使用，不展示给用户）

| 问法 | 内部字段 |
|---|---|
| 早上起来的状态 | `open` |
| 今天最好的时刻 | `high` |
| 今天最糟的时刻 | `low` |
| 睡前的状态 | `close` |
